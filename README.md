# dallaspowerwashingpro.com

Static site built with `python3 build.py` (pages in src/pages, data in src/data/site.json) into dist/, which
Netlify publishes (netlify.toml). Checks: `python3 scripts/check.py`, `python3 scripts/check_old_urls.py`,
`python3 scripts/similarity.py`. See docs/ for the Playbook 2.0 records, decisions, QA and image list.
